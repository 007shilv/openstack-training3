# 第四章 openEuler与双节点实验环境

## 学习目标

了解openEuler的发展、社区和技术定位；掌握openEuler 24.03 LTS SP3双节点实验拓扑；正确配置两块网卡和两块50 GiB数据盘；能在安装OpenStack前验证主机身份、地址、时间、仓库和磁盘边界。

## 4.1 openEuler操作系统概述

openEuler是面向数字基础设施的开源操作系统社区，覆盖服务器、云、边缘和嵌入式场景。社区、整机和软件伙伴共同维护生态，商业发行版可在社区技术基础上提供产品化支持。教学使用社区版本，目的在于理解开放协作、软件包管理、服务管理和国产软硬件适配。

openEuler 24.03 LTS SP3基于Linux 6.6内核，官方定位覆盖服务器、云和AI工作负载，并提供x86_64、AArch64等多架构介质。本实验使用x86_64虚拟机。系统版本必须通过`/etc/openEuler-release`核验，不能仅凭ISO文件名判断。

## 4.2 实验拓扑与资源规划

| 节点 | 管理地址ens33 | ens34 | 主要职责 | 数据盘 |
| --- | --- | --- | --- | --- |
| controller | 192.168.234.151/24 | 不配置IP | 数据库、消息队列、各服务API与调度、Horizon | 无 |
| compute | 192.168.234.150/24 | 不配置IP | Nova计算、Neutron代理、Cinder/Swift后端 | /dev/sdb、/dev/sdc各50 GiB |

表4-1 双节点实验环境

`ens33`承载管理和API流量，`ens34`作为Provider物理网络接口，不配置管理地址。compute系统盘固定为`/dev/sda`；Cinder使用`/dev/sdb`；Swift使用`/dev/sdc`。顺序和设备名是安全边界，任何不一致都要停止操作。

## 4.3 创建虚拟机

创建两台openEuler虚拟机，为controller分配满足控制服务的CPU、内存和系统盘，为compute分配虚拟化资源，并额外增加两块50 GiB虚拟磁盘。两台虚拟机各配置管理网卡与Provider网卡。实验中不要创建或恢复未经教师确认的快照；本书不把快照当作跳过验证的理由。

## 4.4 安装openEuler 24.03 LTS SP3

使用官方镜像并在安装前核对SHA-256。选择最小或服务器环境，设置时区为Asia/Shanghai，按教学要求创建管理账户。首次启动后检查：

```bash
cat /etc/openEuler-release
uname -r
hostnamectl
ip -br address
lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINTS
```

固定controller与compute主机名和管理地址。`ens34`必须显示为UP或DOWN但无IPv4/IPv6业务地址。compute应显示`/dev/sda`为系统盘，`/dev/sdb`与`/dev/sdc`均为50 GiB整盘。

## 4.5 终端选择

Windows可使用Xshell、SecureCRT或系统自带PowerShell连接SSH。三者只承担终端输入，不改变Linux命令本身。本书不再讲解下载、按钮、会话管理等基础操作；使用商业软件时应从官方渠道下载并遵守许可。连接新主机时必须核对SSH主机指纹，不能无条件信任未知密钥。

## 4.6 安装前检查

```bash
getent hosts controller compute
ping -c 2 controller
ping -c 2 compute
chronyc tracking
ip -4 -o addr show ens33
ip -o addr show ens34
findmnt -nro SOURCE /
lsblk -s -nrpo NAME "$(findmnt -nro SOURCE /)"
```

检查结果要写入实验记录，包括命令、时间、节点和结论。存储初始化前还要再次执行更严格的整盘、容量、祖先、挂载、分区、签名和LVM检查，不能依赖本章一次性结果。

> 素养拓展：openEuler与OpenStack的生态建设来自大量组织和个人长期协作。使用开源成果时要尊重许可证、记录来源、回报缺陷，并以可复现的测试承担工程责任。

## 4.7 小结与习题

本章建立了信创化双节点实验底座。地址、网卡和磁盘角色必须在后续每个关键阶段保持一致。

1. 为什么Provider网卡不配置管理IP？
2. 如何证明`/dev/sdb`不是根盘祖先？
3. LTS与SP版本标识分别表达什么？
4. 为什么SSH主机指纹是实验安全边界？
