# 第三章 OpenStack技术与生态体系设计说明

## 1. 编写目标

第三章以第二版第三章为底板，保留“3.1 OpenStack技术简介”这一节，将原“3.2 体验原生OpenStack云平台”改为“3.2 OpenStack生态体系”。正文从概念、架构、服务协作、项目生态和版本边界逐层展开，不写成部署说明、验证报告或界面操作手册。

本章面向首次系统接触OpenStack的高职学生。读完本章后，学生能够说明OpenStack的定位、逻辑架构、核心服务、扩展项目、访问方式、资源对象关系和版本演进，并能够把后续章节的Keystone、Glance、Placement、Nova、Neutron、Cinder、Swift和Horizon放回完整云平台中理解。

## 3. 内容详略

逻辑架构、八个核心服务、资源对象关系、实例创建协作、版本边界和Antelope教学平台属于本章重点，需要结合图表展开说明。Heat、Ironic、Manila、Octavia和Barbican等常用扩展服务说明定位与典型用途；Magnum、Cyborg、Ceilometer和Aodh等项目以建立生态认知为主，简要介绍。

社区历史仅保留理解开放治理所需的关键节点。版本名称不罗列完整字母表，只比较与本教材时间边界直接相关的Antelope、Gazpacho和Hibiscus。

## 4. 事实与资料边界

所有OpenStack架构、服务、版本状态和发布时间均以OpenStack、OpenInfra及各项目官方文档为准，资料截止时间为2026年7月31日。

- 2026.1 Gazpacho是截止时间内最新正式发布版本，发布日期为2026年4月1日。
- 2026.2 Hibiscus在截止时间内处于开发阶段，计划于2026年9月30日发布，正文不得把它写成已经发布。
- 本教材实验环境采用Antelope系列软件包，教材必须区分“产业和社区最新版本”与“教学部署版本”。
- 对项目状态、支持周期和接口能力的表述，不使用来源不明的博客或营销文章替代官方资料。

研究来源登记到第三章资料文件中，教材正文不插入网址清单、访问日期、编写规则或研究过程说明。
