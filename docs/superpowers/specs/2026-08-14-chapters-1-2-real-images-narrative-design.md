# 第1—2章叙事化正文与真实图片增强设计

## 一、修订目标

第1—2章以第二版教材为底板，继续保留现有知识结构、字体字号和版心。正文只承担知识叙述、概念解释、产品介绍与图文分析，不写入编写规则、资料筛选过程、版本维护提醒或面向作者的说明。

## 二、正文叙事规则

1. 删除或改写“教材不能……”“本章保留……”“图中不采用……”“使用时核对……”等编辑性句子。
2. 必须保留的知识改成客观叙述。例如将“教材不罗列全部服务”改成“公有云服务通常可归入计算、网络、存储、数据库、平台服务和治理服务等类型”。
3. 正文不解释作者为什么选择某项资料，也不讨论图片为何没有采用某项预测数据。
4. “一．二．”及“1．2．”层级继续用于组织知识内容，不用于罗列编写要求。
5. 图前必须在正文中自然引用，图后必须解释图中对象、界面区域或资源关系。

## 三、图片类型与数量

采用“实景照片 + 官方产品截图 + 必要架构图”的混合方式。

### 1. 第1章

- 保留5幅概念图和数据图。
- 增加2幅真实数据中心图片，分别表现机柜与服务器基础设施、数据中心运行环境或运维场景。
- 数据中心实景优先采用具有明确开放许可的高清图片。

### 2. 第2章

- 保留7幅产品架构与比较图。
- 增加约7幅产品界面截图：VMware Cloud Foundation、Citrix DaaS、Windows Admin Center或Azure Local、两种国内私有云平台、国内公有云控制台和国际公有云控制台。
- 截图优先取自厂商官网、官方产品文档或公开演示资料，避免使用来源不明的二次转载图。

## 四、图片内部文字

1. 图片内部只出现产品名称、组件名称、资源对象、界面功能和必要数据。
2. 禁止在图片中加入“仅供参考”“不作为结论”“图中不采用预测值”“使用时核对”等规则性或免责声明式文字。
3. 图片内部不得出现教材编写过程、资料选择过程、版权处理过程或版本维护过程。
4. 图片文字保持与正文接近，最小不得低于正文小1.5号的可读范围。
5. 产品截图可以增加简洁编号框或局部放大，但标注只能解释功能对象，不得写成操作规则或作者说明。

## 五、图注与素材登记

1. 图注继续采用章节独立编号，例如“图1.6”“图2.8”。
2. 图注只写图片对象和主题；必要时以简短“资料来源”注明权利人或官方文档。
3. 完整来源网址、获取日期、截图范围、许可状态和出版前授权事项写入独立素材登记表，不进入教材正文。
4. 架构图仍保存SVG和2400×1400 PNG；产品截图保存原始高清图和用于书稿的裁剪图。

## 六、正文与图片对应关系

每幅实景图或产品截图采用相同的叙事顺序：

1. 正文提出本段所讲的环境或产品能力。
2. 使用“如图X.X所示”引出图片。
3. 图片展示实景或实际产品界面。
4. 图后说明可观察到的机柜、资源池、导航区、项目区、监控区或服务目录等对象，并解释其与本节知识的关系。

## 七、验收要求

- 正文和图片中均无编辑规则、免责声明和作者工作说明。
- 第1章至少新增2幅实景图片，第2章至少新增7幅真实产品截图。
- 所有新增图片均有正文引用、图注和图后分析。
- 图片来源可追溯，原始文件与书稿文件分别保存。
- Word正文、标题、图注和页边距继续符合第二版样式。
- 第3章及后续内容不因本次第1—2章修订发生变化。
