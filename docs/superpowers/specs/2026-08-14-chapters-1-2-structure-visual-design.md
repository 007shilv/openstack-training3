# 第1、2章层次、详略与图文优化设计

日期：2026-08-14

适用范围：第三版教材第1章、第2章

底板：`云计算基础架构平台构建与应用（第二版初稿）.docx`

## 1. 目标

在不改变第二版教材基本版式和教学语气的前提下，重新组织第1、2章的内容层次，修正正文格式，补齐产业、环境和架构图，使正文、插图、图注和解释形成连续的教材叙事。

本轮只修改第1、2章并生成独立审阅稿。用户审阅通过前，不继续修改后续章节，也不替换正式工作母稿。

## 2. 内容层次

章标题继续使用“第一章、第二章”，节标题继续使用“1.1、1.2”“2.1、2.2”等格式并进入目录。

每个节标题下至少设置两个正文内部层级：

1. 第一层使用中文数字和全角点号，如“一．云计算的基本特征”。
2. 第二层使用阿拉伯数字和全角点号，如“1．按需自助服务”。
3. 两级均属于正文内部层次，不使用 Heading 3，不进入目录。
4. 层级标题之后必须有连续讲解，不能退化为提纲或定义清单。

## 3. 详略原则

采用“核心原理详细讲、产品事实适度讲、易变信息简要讲”的方法。

### 3.1 第一章详写内容

- 云计算定义与五个基本特征。
- 云计算环境中用户、服务入口、管理控制、资源池和物理基础设施的关系。
- IaaS、PaaS、SaaS 的能力边界和责任划分。
- 公有云、私有云、社区云、混合云的含义及适用场景；重点仍放在教学中常用的公有云、私有云和混合云。
- 云原生、智算云、边缘云、FinOps、绿色与可信云之间的关系。

第一章简写计算模式历史细节、逐年产业数字和具体厂商产品目录。历史只保留演变因果，产业数据只保留能够说明趋势的核定事实。

### 3.2 第二章结构与详略

第二章大体恢复第二版的五节骨架，不能把厂商技术体系压缩为少量产品路线概述。第二版第二章约2.2万个非空白字符，当前稿约5500个非空白字符；本轮目标为1.8万至2.3万个非空白字符，并通过插图和层级改善可读性，而不是机械凑字数。

#### 2.1 VMware的云计算技术及其相关产品

- 详写服务器虚拟化基础，包括ESXi、虚拟机、集群和vCenter的职责。
- 详写VMware Cloud Foundation的私有云层次，说明vSphere计算、vSAN存储、NSX网络以及运维、自动化和生命周期管理之间的关系。
- 说明虚拟机、容器和现代应用承载的联系，但不堆积版本功能清单。

#### 2.2 Citrix的云计算技术

- 详写应用虚拟化、桌面虚拟化和HDX交付的基本原理。
- 详写Citrix DaaS中Citrix Cloud控制面、Workspace/Gateway、Cloud Connector、资源位置和VDA之间的关系。
- 说明本地、AWS、Azure和Google Cloud资源位置可以形成混合交付，但不把Citrix简单写成通用IaaS云平台。

#### 2.3 微软私有云虚拟化技术Hyper-V

- 详写Hyper-V虚拟化结构，包括父分区、子分区、VMBus、虚拟交换机和虚拟磁盘。
- 详写故障转移群集、Storage Spaces Direct、Windows Admin Center或System Center在私有云管理中的作用。
- 更新到Azure Local和Azure Arc的混合管理关系，说明Hyper-V仍是基础虚拟化技术，Azure Local是面向本地基础设施的现行平台路线。

#### 2.4 国内私有云相关产品

- 详写国内私有云的通用技术架构：硬件资源、虚拟化、资源池、云管理、安全、运维和服务门户。
- 选择华为云Stack、阿里云Apsara Stack、EasyStack、ZStack等代表性路线作适度介绍；重点说明技术定位和适用边界，不罗列营销功能。
- 详写国产信创云生态中处理器、openEuler等操作系统、OpenStack等云平台、数据库、中间件和应用生态的协同关系，并为后续openEuler与OpenStack实训建立联系。

#### 2.5 知名公有云平台简介

- 先讲公有云区域、可用区、资源池、服务目录、统一身份和按量计量等稳定结构。
- 国际平台适度展开AWS、Microsoft Azure和Google Cloud；国内平台适度展开阿里云、华为云和腾讯云。
- 比较IaaS、PaaS、数据与AI平台、混合管理和生态能力，不作厂商排名，不记录易变的价格、区域数量和页面布局。
- 章末详写数据位置、时延、成本、运维能力、迁移路径和厂商锁定风险的选择方法。

第二章简写厂商发展历史、宣传口号、全部产品清单及频繁变化的界面、价格、规格和区域数量。相似能力通过对比图集中表达，避免重复铺陈。

### 3.3 重点段落写法

重点内容按“概念—图示—元素解释—实际场景—注意事项”的顺序展开。一般了解内容控制在一至两个自然段。每个自然段原则上不超过240个中文字符，避免大段堆叠。

## 5. 字体与版式

- 正文：宋体10.5磅，沿用第二版正文段落属性和首行缩进。
- 内部层级标题：宋体10.5磅，与第二版“一．”“1．”层级保持一致，不进入目录。
- 图内文字：宋体，常规为10.5磅；复杂图最低不得小于9磅。
- 图注：宋体9磅、加粗、居中。
- 图号：每章独立连续编号，使用“图1.1、图1.2”“图2.1、图2.2”，不使用小节三级编号。
- 页面尺寸、页边距、页眉页脚、章标题和节标题样式均继承第二版底板。

在候选Word中逐段检查第1、2章正文的有效字体和字号，不能只依赖样式名称推断。英文和数字应与同段中文协调，不得出现整段字体漂移。

## 6. 审阅与验收

1. 第1、2章每个节都有“一．”层级，重点主题下有“1．”层级。
2. 重点内容有充分解释，一般内容没有无意义扩写。
3. 12幅图均已插入Word，其中第一章5幅、第二章7幅；图号、正文引用和元素解释一一对应。
4. 图内最小文字不小于9磅，打印与PDF渲染后清晰可读。
5. 正文、内部标题和图注的字体字号与第二版一致。
6. 产业数字和产品定位可追溯到正式来源，动态预测与实际值明确区分。
7. 生成独立Word/PDF审阅稿，视觉抽查目录、章首页、每幅图所在页、跨页段落及第3章转场。
8. 用户确认后才将第1、2章结果合入工作母稿并继续后续章节。
