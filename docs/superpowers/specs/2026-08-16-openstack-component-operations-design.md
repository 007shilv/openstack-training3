# OpenStack组件运维章节设计

日期：2026年8月16日
适用书稿：《云计算基础架构平台构建与应用》第三版当前工作稿

## 1. 目标与范围

本轮在当前第十三章后半部分继续编写OpenStack组件运维内容，不新增正式Word文件，也不顺延第十四章及后续章节编号。第十三章名称调整为“OpenStack云平台初始化与组件运维”，现有13.1—13.4的Horizon原理、安装和平台初始化内容保留。

本设计记录用户在当前工作稿上的最新编号决定，替代2026年8月12日总体设计中“另设第十四章运维并顺延后续章节”的安排；其他总体写作、版式和安全要求继续有效。

运维内容以第二版原第十三章的对象顺序和叙事方法为底板，迁移到openEuler 24.03 LTS SP3、OpenStack 2023.1 Antelope双节点环境。保留“说明对象与场景—逐条输入命令—展示真实结果—解释字段与状态—在必要处展示Dashboard界面”的教材结构，删除旧版重复截图、旧命令和失效界面。

新增八节：

## 3. 运维任务

### 3.1 Keystone

创建独立项目、用户和组，完成角色授权；查看域、项目、用户、组、角色、服务和端点；说明用户禁用、项目禁用、错误域和缺少角色时的登录表现；最后按对象依赖关系清理本节对象。

### 3.2 Glance

查看镜像列表和详情；上传小型测试镜像；修改名称、可见性、保护属性和扩展属性；比较管理员与普通项目的镜像可见范围；解除保护后删除任务镜像。

### 3.3 Placement

查看资源提供者、资源清单、特征、用量和分配信息；解释VCPU、MEMORY_MB、DISK_GB、Generation和Allocation。Placement操作以只读查询为主，不人工修改nova-compute维护的资源清单和分配记录。

### 3.4 Nova

查看计算服务、Hypervisor、实例规格和配额；创建公有与项目专用实例规格；创建实例并执行启动、停止、软重启、暂停或搁置等生命周期操作；创建实例快照；说明实例状态、任务状态和电源状态；清理本节实例、快照和专用规格。

### 3.5 Neutron

查看网络代理、网络、子网、路由器、端口和安全组；在隔离项目中创建网络、子网、路由器和安全组规则；结合实例说明端口、固定IP和浮动IP；按依赖顺序解除路由器接口并清理网络资源。

### 3.6 Cinder

查看卷服务、卷类型和可用区；创建卷、修改名称、扩容、挂载和卸载；创建卷快照并由快照创建新卷；说明available、in-use、creating和deleting等状态；按依赖关系清理卷与快照。

### 3.7 Swift

查看账户、容器和对象；创建容器、上传小对象、下载并比较内容、修改对象元数据；说明容器与对象的层次、对象名称和元数据；删除对象后再删除容器。

### 3.8 Horizon

使用任务用户登录Dashboard，展示项目切换、镜像、实例、网络、卷和身份对象页面。界面操作与前述命令行任务一一对应，只保留能说明对象关系和状态变化的关键页面。

## 4. 沙箱与资源边界

所有可写操作限定在独立项目`bookops`中，普通用户使用`bookops-user`，教材密码统一为`qwer1234`。任务资源统一使用`bookops-`前缀，例如`bookops-image`、`bookops-flavor`、`bookops-net`、`bookops-subnet`、`bookops-router`、`bookops-secgroup`、`bookops-server`、`bookops-volume`和`bookops-container`。

既有admin、service、demo等对象只读引用，不修改或删除。Placement由Nova维护的资源提供者、清单和分配记录只读查询。Cinder的`cinder-volumes`卷组、Swift的`/dev/sdc`文件系统、服务配置、数据库和端点不在本轮修改范围内。

每个创建命令都记录返回对象ID。清理时使用本轮记录的精确ID，并遵循“实例和挂载关系—端口和浮动IP—路由器接口—子网—网络—镜像、卷与快照—身份对象”的依赖顺序。清理前重新核对名称、项目和ID，不按模糊名称批量删除。

## 5. 命令与截图

教材中的每条命令均带第二版风格的系统提示符，由读者逐条手工输入，不出现Python程序、一键脚本或自动化验证器。命令输出来自实际OpenStack实验环境，不虚构对象、状态或返回字段。

命令结果截图使用白底黑字、等宽字体和浅灰边框。若原始终端为黑底白字，只做整体反色、裁边和分辨率调整，不重写输出内容。图片中的中文字号不小于正文1.5号，英文和数字使用Times New Roman或清晰等宽字体。动态令牌、Cookie、密码和会话信息不进入截图。

Dashboard截图通过隔离的无界面浏览器采集，不调用用户当前Chrome会话。登录口令仅在采集进程内使用，不写入截图、日志或项目文件；采集完成后删除浏览器会话数据。界面截图保留当前Horizon品牌、菜单、对象名称和状态，裁去无关浏览器区域。

每章图号继续使用“图13.4、图13.5……”的独立顺序，不采用“图13.5.1”式小节编号。表格继续使用“表13-4、表13-5……”编号。正文先引用并说明图片，再插入图片，图片之后解释关键字段、状态和操作结果；不加入图片备注或编写规则说明。

预计新增24—32幅图片，其中终端结果截图约16—20幅，Dashboard截图约8—12幅。相邻命令输出能够在一幅图中清楚表达时合并展示，避免第二版每条命令机械截图造成篇幅膨胀。

## 6. 内容与语言

正文只说明对象是什么、操作会改变什么、返回字段表示什么以及对象之间的关系。避免作者口吻、验证报告、审计记录、测试规则和“教学活动”等非教材叙事。专业名词第一次出现时给出英文全称和中文解释，后续使用稳定简称。

运维操作以新版OpenStackClient命令为主，必要时使用组件客户端或HTTP接口，但正文不出现内部采集程序。第二版仍适用的操作逻辑可以保留，命令参数、服务名称、界面路径和截图全部以Antelope实验环境实测结果为准。

本章末自然融入资源隔离、最小权限、操作复核和数据责任等职业素养内容，不另设课堂讨论或复习思考题。
